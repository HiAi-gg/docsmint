# DocsMint 0.9.0 — consistent MCP document listings

## Highlights

- Return folder and category names from document listings so REST, SDK, and MCP
  structured output agree.
- Refresh document-list cache entries after folder or category changes for all
  members of a shared workspace.
- Publish clearer MCP tool definitions and stable output schemas, along with
  the canonical public capability catalog.
- Reject category-scoped document creation in a folder assigned to a different
  category.

## Compatibility and operations

- No database migration is required.
- Existing document visibility and permissions remain unchanged.
- The public document-list response now includes location labels already
  declared by the SDK type.

## Verification

- Cache regression coverage verifies that a category or folder change clears
  cached lists for other members of the same workspace without clearing lists
  from unrelated workspaces.
- Release CI verifies all 21 MCP tools through the assertion-bound public
  client.
