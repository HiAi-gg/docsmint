# DocsMint 0.9.2 — Glama Server listing preparation

## Highlights

- The repository now provides a schema-valid `glama.json` for claiming the
  open-source DocsMint MCP Server listing through the GitHub organization.
- The MCP guide explains how to run the published stdio bridge with Bun, a
  reachable DocsMint API URL, and an API key. The hosted DocsMint Cloud
  Connector remains a separate listing and needs no local server.
- The MCP catalog validator checks the Glama Server claim format.

## Installation and compatibility

For DocsMint Cloud, connect an MCP client to `https://docsmint.com/mcp` using
the [Cloud setup guide](https://docsmint.com/mcp/connect).

For self-hosted DocsMint, run your API, create an API key, and set
`HIAI_DOCS_URL` and `HIAI_DOCS_API_KEY` before starting the stdio bridge:

```sh
npx --yes --package @hiai-gg/docsmint@0.9.2 docsmint-mcp
```

The binary requires Bun. See the [MCP guide](https://github.com/HiAi-gg/docsmint/blob/main/packages/mcp-server/README.md)
for client configuration. Existing SDK, CLI, API, and MCP capabilities remain
compatible. No database migration is required.
