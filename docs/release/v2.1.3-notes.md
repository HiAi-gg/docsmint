# DocsMint OSS 2.1.3

This release includes the version history changes prepared for the unpublished 2.1.2 release. Preview and restore historical document content without reloading the editor. Unchanged saves no longer add automatic history entries, and restoring a version protects the document from stale saves and collaboration rooms.

Large legacy Markdown versions render without autosaving their parsed representation. Preview follows the current editor mode, and a restored revision uses its own editor cache entry.

Existing REST and MCP contracts remain compatible.
