# DocsMint OSS 2.0.4

## Mobile navigation focus

The mobile navigation trigger may be removed while a modal drawer is open and
recreated after closing. Both the standalone shell and the public app-shell host
now restore focus after that closing render, falling back to the replacement
trigger when the original node is detached. Reopening the drawer cancels restoration.

The public API, MCP tool catalog, permission model, and storage schema are unchanged.
