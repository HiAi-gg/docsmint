# DocsMint OSS 1.0.3

This release fixes MCP input schemas for clients that add an account-routing field
at the root of an operation union. Clients can select a connection while the
exported schema still rejects unknown and operation-incompatible fields. Server
validation, tool handlers and authorization behavior are unchanged.

Install the public SDK and self-hosted MCP bridge:

```sh
bun add @hiai-gg/docsmint@1.0.3
bunx @hiai-gg/docsmint@1.0.3 --help
```

Use `docsmint-mcp` with your own self-hosted `HIAI_DOCS_URL` and
`HIAI_DOCS_API_KEY`, or connect to [DocsMint Cloud](https://docsmint.com/mcp/connect)
using its normal OAuth flow. Cloud must adopt this published SDK before its hosted
MCP schemas change. Updating only a source submodule does not update Cloud.

The release includes compatible security updates for the MCP SDK, Vite,
ProseMirror view and source-map-js. Existing APIs, SDK exports and workspace
assertion contracts are preserved. No database migration or new required
environment variable is introduced by this patch.
