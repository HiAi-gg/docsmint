# DocsMint 0.8.4 — Clearer MCP setup, stronger access verification

Connect your AI agent to DocsMint with clearer guidance for both DocsMint Cloud
and self-hosted workspaces. This release also expands access-control regression
coverage and checks that public package exports and MCP binaries exist before
packaging.

## Highlights

- **A clearer starting point for agents.** npm and MCP catalog descriptions
  explain Cloud onboarding and the self-hosted stdio bridge, with direct setup
  links and guidance for scoped credentials.
- **Documented Cloud browser authorization.** The MCP guide covers OAuth-capable
  clients and API-key connections. Hosted OAuth is a Cloud capability; it does
  not install an OAuth server in self-hosted DocsMint.
- **More access-control regression coverage.** Checks cover category scopes,
  external tenant assertions, scoped attachment deletion, workspace tags, and
  partial category updates.
- **More repeatable release verification.** Built exports and MCP binaries are
  checked before packaging. An offline retrieval baseline supports repeatable
  evaluation without claiming an improvement in live search quality.

## Get started

- [Connect DocsMint Cloud](https://docsmint.com/mcp/connect?source=github_mcp)
- [Self-host with Docker Compose](https://github.com/HiAi-gg/docsmint/tree/v0.8.4#quickstart)
- [Configure your MCP client](https://github.com/HiAi-gg/docsmint/blob/v0.8.4/packages/mcp-server/README.md)

Install the SDK package:

```bash
bun add @hiai-gg/docsmint@0.8.4
```

For the self-hosted MCP bridge, first configure `HIAI_DOCS_URL` and
`HIAI_DOCS_API_KEY` for your running DocsMint deployment, then run:

```bash
npx --yes --package @hiai-gg/docsmint@0.8.4 docsmint-mcp
```

## Upgrade notes

No database migration or deployment configuration change is required by 0.8.4.
The 17 MCP tools, 2 prompts, 3 resources, and public SDK/API contracts are
preserved. Catalog refreshes may lag behind publication.

Docker Hub images use matching service tags:
`vgalibov/docsmint:api-v0.8.4`, `vgalibov/docsmint:web-v0.8.4`, and
`vgalibov/docsmint:caddy-v0.8.4`. These are components of the complete stack;
Caddy supplies the reverse proxy. There is no bare `latest` image.
