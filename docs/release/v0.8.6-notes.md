# DocsMint 0.8.6 — Docker listing and installation links

DocsMint brings your documents and AI agents into one knowledge workspace.
This patch completes the publication improvements introduced in 0.8.5.

## What's improved

- Docker Hub descriptions now use the repository update endpoint, correcting
  a 403 caused by sending updates to the namespace read endpoint.
- The LobeHub overview links directly to Docker Hub and the self-hosted setup guide.
- API, Web, and Proxy images retain their clear component names and release metadata.

## Get started

[Connect DocsMint Cloud](https://docsmint.com/mcp/connect?source=github_release) ·
[Self-host with Docker](https://github.com/HiAi-gg/docsmint/tree/v0.8.6#quickstart) ·
[Docker Hub images](https://hub.docker.com/r/vgalibov/docsmint) ·
[SDK, CLI, and MCP package](https://www.npmjs.com/package/@hiai-gg/docsmint)

```bash
bun add @hiai-gg/docsmint@0.8.6
bunx --package @hiai-gg/docsmint@0.8.6 docsmint --help
```

For self-hosted MCP, configure `HIAI_DOCS_URL` and `HIAI_DOCS_API_KEY` for your
running deployment, then use
`bunx --package @hiai-gg/docsmint@0.8.6 docsmint-mcp`.

## Upgrade notes

No database migration, API change, or credential rotation is required.
Docker components are `vgalibov/docsmint:api-v0.8.6`,
`vgalibov/docsmint:web-v0.8.6`, and `vgalibov/docsmint:caddy-v0.8.6`.
Caddy is the supporting proxy, not a standalone DocsMint installation.
