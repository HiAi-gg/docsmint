# DocsMint 0.10.0 — Focused MCP catalog

## Highlights

The MCP bridge now presents 20 focused tools while retaining all 31 operations
from 0.9.4. Browse versus search, document views, workspace structure, and
create/update actions use explicit selectors. Deletion, version restore,
trash restore, and permanent purge remain separate tools.

## Installation and compatibility

DocsMint Cloud uses the separate hosted endpoint at
`https://docsmint.com/mcp`; follow the [Cloud setup guide](https://docsmint.com/mcp/connect).
Self-hosted deployments run their own DocsMint API and connect the stdio bridge
using `HIAI_DOCS_URL` and `HIAI_DOCS_API_KEY`:

```sh
npx --yes --package @hiai-gg/docsmint@0.10.0 docsmint-mcp
```

The binary requires Bun. MCP clients calling the former tool names must adopt
the [31-to-20 mapping](https://github.com/HiAi-gg/docsmint/blob/main/packages/mcp-server/README.md).
There are no legacy aliases in the discovery catalog. SDK, CLI, REST,
self-hosted API-key authorization, prompts, and resources retain their
existing contracts. There is no database migration or hosted OAuth change.
The Cloud MCP service must deploy a matching package before hosted clients
use the compact tool names.

## Verification

Release CI validates the 20-tool catalog and 31 operation routes, public
package, MCP Registry and LobeHub metadata, scope propagation, and stdio
startup before publication.
