# DocsMint OSS 2.1.4

The self-hosted OpenAPI specification now describes 84 operations, including API key and workspace discovery. It covers document pagination, exports and imports, attachments, version history, sharing, and operator operations.

The contract distinguishes browser sessions, scoped API keys, and operator credentials. Existing routes, SDK calls, workspace permissions, and MCP tools remain compatible. This release adds no schema migration.

See the [OpenAPI contract](https://github.com/HiAi-gg/docsmint/blob/v2.1.4/docs/openapi.json) and [self-hosted deployment guide](https://github.com/HiAi-gg/docsmint/blob/v2.1.4/docs/DEPLOYMENT.md). SDK users can update to `@hiai-gg/docsmint@2.1.4`.
