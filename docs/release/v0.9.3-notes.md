# DocsMint 0.9.3 — Complete MCP document management

## Highlights

- The self-hosted MCP bridge now exposes 31 tools. Agents can create and manage
  tags, assign tags to documents, rename or move folders, rename or reorder
  categories, and list, restore, or permanently purge documents in trash.
- The new tools use the existing DocsMint API and its workspace/category key
  permissions. Permanent deletion is an explicit, destructive operation on a
  document already in trash.
- The public SDK adds typed trash-list, restore, and purge methods. MCP Registry
  and LobeHub metadata match the runtime catalog.

## Installation and compatibility

For DocsMint Cloud, use the separate hosted endpoint at
`https://docsmint.com/mcp` and follow the
[Cloud setup guide](https://docsmint.com/mcp/connect).

For self-hosted DocsMint, run your own API, create an API key, and configure
`HIAI_DOCS_URL` and `HIAI_DOCS_API_KEY` before starting the stdio bridge:

```sh
npx --yes --package @hiai-gg/docsmint@0.9.3 docsmint-mcp
```

The binary requires Bun. Existing SDK, CLI, API, and MCP clients remain
compatible. No database migration or Cloud OAuth change is required. See the
[MCP guide](https://github.com/HiAi-gg/docsmint/blob/main/packages/mcp-server/README.md)
for tool permissions and client configuration.
