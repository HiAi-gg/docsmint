# DocsMint OSS 2.1.5

REST and HTTP MCP responses include a server-issued request ID. Preserve it when reporting an authorization or request failure. The OpenAPI contract includes examples for reading index state, refreshing a document index, and retrying warning stages.

The existing REST paths, credentials, and MCP tools remain compatible. This release adds no migration.

See the [OpenAPI contract](https://github.com/HiAi-gg/docsmint/blob/v2.1.5/docs/openapi.json) and [self-hosted deployment guide](https://github.com/HiAi-gg/docsmint/blob/v2.1.5/docs/DEPLOYMENT.md). SDK users can update to @hiai-gg/docsmint@2.1.5.
