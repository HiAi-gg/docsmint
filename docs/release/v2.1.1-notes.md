# DocsMint OSS 2.1.1

This patch updates the supported build/runtime baseline to Bun 1.4.4 and refreshes SvelteKit 3.1.1, Vite 8.3.5, adapter-node 6.0.1, vite-plugin-svelte 7.3.1, and Better Auth/core 1.7.15. Existing MCP tools, REST endpoints, permissions and result envelopes are unchanged.

Compatible transitive updates fix the reported fast-uri, browserslist, baseline-browser-mapping and serialize-javascript advisories. Production dependency audit reports no advisories. Two moderate build-tool advisories remain in glob and minimatch: their available fixes require major upgrades outside the current upstream dependency ranges. They are recorded in the security report rather than forced globally across incompatible edges.

This is a source release candidate until the normal CI, package/provenance, container and live acceptance gates have passed. No previous release tags are changed.
