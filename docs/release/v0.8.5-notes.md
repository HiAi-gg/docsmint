# DocsMint 0.8.5 — Clearer setup, consistent releases

**Turn your documents into knowledge you and your AI agents can use.**

DocsMint 0.8.5 makes it easier to choose a deployment, connect your tools, and
find the right package or container. This is a documentation and distribution
presentation release; the application and public API remain compatible.

## What's improved

- **Choose your starting point.** Clearer Cloud and self-hosted guides explain
  how to connect a client or install the complete workspace.
- **Install one package.** `@hiai-gg/docsmint` contains the TypeScript SDK,
  `docsmint` CLI, and `docsmint-mcp` bridge.
- **Find the right Docker image.** The image guide explains the API, web
  application, and supporting Caddy reverse proxy with matching versioned tags.
- **Follow working examples.** README documentation links work on npm, and the
  SDK quick start handles an empty document list.

## Get started

[Connect DocsMint Cloud](https://docsmint.com/mcp/connect?source=github_release)
or follow the [self-hosted Docker quickstart](https://github.com/HiAi-gg/docsmint#quickstart).

For a running deployment, install the SDK or run a client:

```bash
bun add @hiai-gg/docsmint@0.8.5
bunx --package @hiai-gg/docsmint@0.8.5 docsmint --help
bunx --package @hiai-gg/docsmint@0.8.5 docsmint-mcp
```

The stdio MCP bridge uses `HIAI_DOCS_URL` and `HIAI_DOCS_API_KEY` to connect to
an existing deployment. See the [MCP guide](https://github.com/HiAi-gg/docsmint/blob/v0.8.5/packages/mcp-server/README.md)
for Cloud and self-hosted configuration.

## Upgrade notes

No new database migration, API change, or credential rotation is required.
Use matching Docker tags `api-v0.8.5`, `web-v0.8.5`, and `caddy-v0.8.5` from
`vgalibov/docsmint`. Caddy provides the reverse proxy; it is one component of
the complete Compose deployment.
