## Task 2 commands

The live command builds the ignored public launcher artifacts first and requires
explicit, matching test-only PostgreSQL, Redis DB, Seaweed, API, and embedding
service variables. It fails closed on any launcher/fixture mismatch and does not
read or modify `.env`:

```sh
bun run test:contract:scoped-live
bun run release:check:contract-evidence:task2
bun test scripts/contract-evidence-validator.test.ts
bun test packages/sdk/src/client.test.ts packages/mcp-server/src/server.test.ts packages/mcp-server/src/catalog-contract.test.ts
bun run typecheck
bun run lint
git diff --check
```

The following command is expected to fail during Task 2 and must pass only
after Task 3 replaces the transition with a completed `true` declaration:

```sh
bun run release:check:contract-evidence
```
